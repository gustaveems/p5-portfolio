01

Self-directed · 2026 → present · ML · computer vision · public data

VacancyOracle — The ML Successor

  • ParkScan's hand-tuned rules become measured models: 1,050 hand-labeled Dutch commercial addresses, 4,071 Street View images embedded locally with SigLIP, BAG registry features, and an evaluation protocol frozen before any model was fit.
  • Audited my own evaluation and caught leakage: 843 labeled units sit in only 468 buildings, so splitting by unit let a building's neighbours give its answer away. With building-grouped CV the fused model drops from 0.55 to 0.37; the SigLIP image probe holds at 0.43 PR-AUC at a 3% vacancy rate, against 0.03 for ParkScan's original rules.
  • Found a confound: vacancy is labeled 3× more often in Street View photos from before 2016, and photo age alone beats every trained model across cities. Capture year is now a mandatory control.
  • Pre-registered a sign-reading test (on-device OCR for “TE HUUR” boards), re-run on 2,511 facade-aimed images: a clean null — the vacant facades carry no letting boards. Now hunting recent-photo Amsterdam vacancies with a model-ranked label queue.

Code ↗ baselines, pre-registrations & audits in the repo
